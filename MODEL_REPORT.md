# Model report

## Career-family models

Career-family training uses **only** `data/synthetic/career_training_profiles.csv`, generated by `data/generate_career_training_data.py` with seed `20260929`. It contains 1,600 synthetic profiles (400 per education level) and five broad family labels. Labels represent latent synthetic scenarios; they are generated first, then scores are sampled from label-specific distributions. They are not collected student outcomes. No user-collected survey cohort is currently available.

Each education level has a separate feature contract in `backend/ml/feature_engineering.py`, its own pipeline and saved artifact. Academic subjects, aptitudes, interests, technical skills, employability scores, and stream are used where stage-appropriate. The target label is never included in the feature matrix. Missing/nonapplicable values are imputed inside the pipeline. Each stage uses a stratified 80/20 train/test split (`random_state=20260929`) and 5-fold stratified CV on the training partition. Random Forest and XGBoost are compared using training-partition CV; the winner is selected by mean CV macro-F1, and only then is that selected candidate evaluated once on the held-out test partition. Candidate CV metrics and selected-model holdout metrics are saved separately.

**Legacy artifact warning:** the model artifacts and metric files currently present in this checkout were produced before this selection correction. They were selected using held-out test macro-F1. Their reported holdout values are selection-biased and are retained unchanged; they are not corrected-protocol results. No models were retrained as part of the correction. Regenerate them only in an approved isolated artifact destination, then replace production artifacts through a separately reviewed process.

The previously generated detailed metrics, class-wise reports and confusion matrices are in `data/processed/career_model_metrics.json`. They are historical results from the legacy protocol and must not be cited as an unbiased final estimate. The current training code selects by mean 5-fold training-partition CV macro-F1; no results for that corrected protocol are available until training is rerun safely.

**Interpretation limit:** the perfect/near-perfect synthetic scores show that the models learn the generator's deliberately related score patterns. This is not evidence of performance on real students, does not validate the synthetic assumptions, and must not be presented as a real-world accuracy claim. Career guidance remains exploratory; compatibility scoring and the curated career knowledge base provide the separate requirements-based evidence.

## Kaggle synthetic university career-field benchmark

The separately downloaded Kaggle file contains 50,000 synthetic rows. For this benchmark, the 10,960 `Not Placed` rows are removed, leaving 39,040 records across 16 placed career-field labels. This is **not a real-student dataset** and it is not pooled with the locally generated synthetic stage profiles because the target definitions and feature contracts differ. It covers university students only, so it does not train or replace the 10th, 12th or Master's models. See `DATA_SOURCES.md` for its Kaggle URL, CC BY-SA 4.0 license, source files and provenance.

The target is the source's `Career_Field`, conditional on placement. Training excludes identifiers, demographics, the derived academic category, interview/employability/placement outcomes, company tier, placement mode and salary. The feature table uses 15 university and skill profile fields. An 80/20 stratified holdout and 5-fold stratified CV use seed `20261010`; model choice is made by mean CV macro-F1, and the holdout is only for final reporting.

| Model | Holdout accuracy | Macro precision | Macro recall | Macro F1 | CV accuracy (mean ± SD) | CV macro F1 (mean ± SD) |
|---|---:|---:|---:|---:|---:|---:|
| Random Forest | 0.392 | 0.368 | 0.465 | 0.378 | 0.393 ± 0.004 | 0.387 ± 0.006 |
| XGBoost | 0.395 | 0.405 | 0.408 | 0.406 | 0.390 ± 0.009 | 0.407 ± 0.009 |

XGBoost is selected by mean CV macro-F1. **The requested 90% accuracy target was not reached** for this 16-class Kaggle career-field task. The results show that the dataset's features do not reliably recover its detailed career-field labels under the stated leakage controls. The saved metrics and class-wise reports are in `data/processed/kaggle_career_model_metrics.json`; the selected, preprocessed pipeline is saved at `backend/models/kaggle/kaggle_bachelor_career_field.joblib` (about 5.5 MB). This benchmark artifact is intentionally not connected to live recommendations: its fields (for example, attendance, study hours and major) are not the same as the CareerPath assessment contract, and fabricating those inputs would make the recommendation score misleading.

## Explainability and live recommendation scoring

SHAP `TreeExplainer` is applied to the selected stage tree model when installed and technically supported; explanations identify both the explained target class and model's predicted top class. The live hybrid score is `0.90 × knowledge/profile compatibility + 0.10 × (model family probability × 100)`. The admin Models view compares each trained Random Forest/XGBoost model with a deterministic `DummyClassifier(strategy='prior')` baseline on the same stratified holdout; baseline metrics are generated by `python -m backend.ml.diagnose_career_models` and saved separately to `data/processed/career_model_diagnostic.json` without changing model artifacts. For 10th Standard, stage-appropriate profile scores and model probabilities are aggregated into broad study-stream guidance; specialized downstream job roles are not recommended at that stage. Missing assessment dimensions are excluded from the profile compatibility denominator. Skill gaps are direct differences between profile scores and career requirements; improvement actions are selected by actual gaps.

The family probabilities currently contribute only 10% because all four family models were trained on synthetic generator labels. Their reported test/CV metrics are synthetic-label agreement, not measured prediction accuracy for real learners. The dedicated Kaggle benchmark is also synthetic, covers only university students, achieved approximately 40% holdout accuracy across 16 career-field labels, and is not wired into the live four-stage service. A real, representative, consented outcome dataset is needed to validate or calibrate these probabilities.

## Public UCI academic benchmark (separate experiment)

The preserved UCI Student Performance Mathematics dataset has 395 records. It predicts disclosed final-grade bands from UCI school/life context. It is supplementary and does not train the career-family model. `G1`, `G2`, and `G3` are excluded from inputs to prevent target/temporal leakage; `G3` supplies the grade-band target only. The previous experiment compares a majority baseline and Random Forest using a stratified 80/20 split and 5-fold CV. Its generated report is `backend/models/MODEL_REPORT_RESULTS.md`. See `DATA_SOURCES.md` for exact provenance and license.

## Reproduce

```powershell
python data/generate_career_training_data.py
python -m backend.ml.train_career_models
python -m backend.ml.train_model
python -m backend.ml.preprocess_kaggle_career
python -m backend.ml.train_kaggle_career_model
```

Seeds are fixed in the generation/training modules. Training writes stage pipelines under `backend/models/career/` and detailed evaluation metrics under `data/processed/`. SHAP explanations are computed for profiles at inference, not fabricated as static training prose.
